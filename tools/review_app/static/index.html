Keyboard shortcuts

1…9choose that answer, save it and go to the next item
Enter / Spaceaccept the suggested answer (dashed yellow border) and go on
→ / D, ← / Anext / previous item without changing anything
Njump to the next item you have not reviewed yet
Uundo: clear your answer for this item
Cadd a short note to this item
Fcycle filter: all / not reviewed / reviewed / answer differs from suggestion
Z or clickenlarge the first image (click a specific image to enlarge it); Esc closes
?show / hide this help
Escback to the task list (everything is already saved)

Every answer is saved immediately to annotations/<task>/labels.json. You can stop at any time and continue later from the same place.

? or Esc to close
